# iCreate: Order Networking — V0.0.75-indev

> **Development milestone:** 75% backend completion. This is an experimental in-development snapshot, not a playable or feature-complete release.

## Highlights

- Persistent orders and delivery receipts, with server-side validation for order ownership, claiming, fulfilment, and cancellation.
- Automated-delivery groundwork with route/claimant/count validation and pending-quantity reservations to prevent overbooking.
- Transaction-safe economy handling for manual delivery payouts and order-cancellation refunds, including purpose-scoped idempotency keys.
- Crash-recovery safeguards that finalize receipts when durable order progress was already applied, without committing cargo a second time.
- Create Redstone Requester bridge groundwork for publishing restock orders, with duplicate active requests suppressed.
- Safer adapter and factory endpoint discovery: broken optional integrations fail closed rather than taking down unrelated logistics.
- Server-stop cleanup for transient logistics registries and regression tests for persistence, malformed saved data, reservations, and recovery.
- GitHub Actions build and regression-test workflow.

## Known limitations

- Train (Portable Storage Interface), Aeronautics airship (Docking Connector), Frogport, and belt delivery adapters are not yet implemented and verified end-to-end.
- The Redstone Requester bridge still needs live-world testing against the pinned Create version.
- This is not yet a playable release; the in-game order-terminal GUI and remaining front-end work are incomplete.
- CI verifies compilation and automated tests, not live Minecraft behavior.

## Backend progress

At the time of this milestone, the project reached **75% backend completion**. Progress has since continued; the repository's current README may report a newer estimate.

## Compatibility target
